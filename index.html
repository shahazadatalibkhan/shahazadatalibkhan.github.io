📊 Summary
🗄️ Hard Backup (Monthly / Yearly) — Firebase pe alag save

Poora data (Medicines, Client, Grahak, Supplier, Bills, Payments, Purchase…) Firebase path ms_agency_hard_backups me month/year folder me save hota hai. Delete ke baad bhi yahan se recover.

🗑️ Dustbin (Soft Delete) — recover later

Delete pe data turant khatam nahi — Dustbin + Firebase ms_agency_trash me jata hai. Client / Grahak / Supplier / Medicine / Bill yahan se restore kar sakte ho.

⚠️ Danger Zone

Pehle Hard Backup banao. Reset pe pehle auto Hard Backup + Dustbin me full snapshot jata hai.

⭐ ZAROORI — Google Lens (sabse sahi)

Photo se free OCR dense Marg bill pe galat / kam items deta hai. Google Lens → Copy all text → Paste se 20/20 lines sahi aate hain.

  1. Format upar Marg ERP / Estimate select rakho
  2. Google Lens se bill scan → Select all text → Copy
  3. Neeche box me Paste → Parse Text
  4. Review table check → Add to Stock
